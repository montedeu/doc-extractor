# doc-extractor

Извлечение реквизитов из текста входящих документов (счета, КП, акты) в JSON фиксированной схемы — так, чтобы система не выдумывала то, чего в документе нет.

## Документ и его поля

**Документ**:
Текст одного входящего документа, поступивший на вход; может оказаться и не документом вовсе (письмо, переписка).
_Avoid_: файл, input

**Тип документа**:
Один из видов: счёт (`invoice`, включая «шот-фактуру»), коммерческое предложение (`commercial_offer`), акт выполненных работ (`act`) или `unknown`.
_Avoid_: категория, класс

**Поставщик**:
Сторона, которая выставляет документ и получает деньги: продавец в счёте, исполнитель в акте, автор КП.
_Avoid_: контрагент, исполнитель (как общее слово), продавец (как общее слово)

**Покупатель**:
Сторона, которой адресован документ и которая платит (покупатель, заказчик); её реквизиты не попадают в поля поставщика.
_Avoid_: клиент, контрагент

**БИН**:
12-значный бизнес-идентификационный номер юридического лица с контрольной цифрой; у ИП вместо него ИИН, который БИНом не считается.
_Avoid_: ИНН, налоговый номер, ИИН (как синоним)

**Итог**:
Сумма к оплате по документу, как она указана в нём самом (строка «Всего к оплате» / «Итого к оплате», а при её отсутствии «Итого»).
_Avoid_: сумма, total (в прозе)

**Позиция**:
Одна строка перечня товаров или услуг: наименование, количество, цена.
_Avoid_: строка, item, товар

## Результат извлечения

**Результат**:
JSON по фиксированной схеме, который система возвращает на один документ.
_Avoid_: ответ, output

**Ответ модели**:
Сырой текст, который вернула языковая модель, до валидации и проверок.
_Avoid_: результат, completion

**Пустой результат**:
Результат, в котором тип `unknown`, все поля null и позиций нет; возвращается, когда ответ модели так и не прошёл валидацию.
_Avoid_: fallback, ошибка

**Сверка с текстом**:
Проверка, что значение, предложенное моделью, действительно присутствует в документе; не найденное значение заменяется на null.
_Avoid_: grounding, верификация, валидация (это про схему)

**Валидация**:
Проверка ответа модели на соответствие схеме (типы, форматы, допустимые значения) — без обращения к тексту документа.
_Avoid_: сверка, проверка (без уточнения)

**Предупреждение**:
Запись в `warnings` о противоречии в документе, исправлении OCR или отклонённом значении.
_Avoid_: ошибка, alert

**Уверенность поля**:
Число от 0 до 1 в `field_confidence`, вычисленное по результатам валидации и сверки с текстом, а не оценённое моделью.
_Avoid_: score, вероятность

## Оценка качества

**Эталон**:
Размеченный вручную правильный результат для документа из тестового набора.
_Avoid_: gold (в прозе), ground truth, ожидаемый ответ

**Исход поля**:
Итог сравнения одного поля с эталоном: верно, галлюцинация, пропуск или неверно.
_Avoid_: ошибка (без уточнения)

**Галлюцинация**:
Поле заполнено, хотя в эталоне null.
_Avoid_: ложное срабатывание, выдумка

**Пропуск**:
Поле null, хотя в эталоне есть значение.
_Avoid_: недоизвлечение, miss

**Неверно**:
Поле заполнено и в эталоне есть значение, но они не совпадают.
_Avoid_: ошибка, mismatch

**Записанные ответы**:
Сохранённые ответы модели на документы тестового набора, по которым eval воспроизводится без запуска модели.
_Avoid_: кэш, моки, фикстуры
