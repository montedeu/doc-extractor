# Предупреждения пишет только код, не модель

Модель склонна выдумывать и предупреждения, а эталоны большинства документов ждут пустой список; к тому же предупреждения, написанные моделью, нельзя проверить тестом. Поэтому `warnings` формируют только детерминированные проверки: сверка с текстом (отклонённое значение), исправление OCR в БИН и контрольная цифра, поиск противоречий (разные суммы к оплате, сумма прописью ≠ цифрами, разные даты составления), отказ валидации.

## Consequences

- Противоречия, которые не описываются правилом, система не заметит; новый вид противоречия — это новое правило в коде и тест на него.
